- 改动：`core/ledger/store.js`、`main/ledger.js`、`main/{index,journal,diary,persist,relation,agent}.js`、`main/rag/index.js`、`test/ledger.test.js`、`scripts/verify-local-llm.mjs`。本地 `ledger/entries.jsonl` 保存来源、发生时间、记录时间、类别、可信度、关联 RAG ID、删除状态；首次启动迁移现存流水、日记、记忆、历史、RAG、关系与情绪时间线，成功后写迁移标记。旧日记仅建立索引，不重新灌入 RAG；聊天记录保留原文而非七天流水里的 60 字裁剪版本。
- 用户变化：后续聊天、戳击、主动发言、日记、记忆与情绪采样留下可追溯记录；模型抽取的旧事实只标为“未经核实的说法”，未给无时间戳的历史补造发生时间。当前账本尚无查看界面，阶段 4 接入。

- 剩余风险：迁移只读取首次启动时可见的旧文件；旧格式中历史消息缺时间戳，故只保留记录时间。账本目前是主进程内部数据，还未提供用户查看或完整删除链路；RAG 摘要与原始资料之间的删除传播留在阶段 4。旧数据源仍保留，阶段 4 的纠错/忘记必须同步这些源和检索索引。

## 阶段 4：可信记忆与用户控制（2026-10-16）

- 改动：`core/ledger/store.js`、`core/{context,diary}.js`、`core/rag/recall.js`、`main/{ledger-actions,agent,diary,journal,persist}.js`、`main/rag/{index,store-io}.js`、`main/ipc/{ledger,settings}.js`、`shared/protocol.js`、`preload/index.js`、设置页及三组测试。账本分“有来源的记录 / 未经核实 / 主观记录”；模型摘录与日记在提示词和召回中明确标注。设置页可看来源和时间、纠错、忘记、导出 JSON；纠错/忘记前有原生确认，导出由系统保存窗口选路径。
- 用户变化：可逐条检查凪为何记得这件事。忘记会清除对应的短期历史、流水或日记、重点记忆、RAG 待嵌队列与已嵌入正文；纠错留下新条目和原 ID 的审计关联，旧正文从账本文件移除。新日记记录其素材来源，忘记素材时会撤回相关日记；已撤销内容不会在后台嵌入或摘要完成后回写。原有语音配置文件和引擎选择未修改。
- 验证：`npm test` 324/325 通过、1 项本机符号链接夹具跳过；`npm run build` 通过；隔离真实 Electron 与 Ollama 32/32，设置页可见来源与可信分类。单测覆盖迁移重试、纠错/删除后账本与历史不含旧正文、待嵌/已嵌入清除、依赖摘要清除、嵌入进行中撤销、跨实例恢复后不复活。
- 剩余风险：旧版记录没有完整的“由哪条经历生成”关系，精确原文和 RAG 摘要覆盖关系可清理，但无法自动证明旧版模型释义的每一种语义转述都已找到；原生确认与保存窗口需真人操作复核。纠错/忘记的跨文件写入尚非事务，若磁盘错误中途发生会返回失败并允许重试，阶段 10 需做故障注入验收。
- 下一阶段前置条件：主动陪伴触发要统一经过勿扰、只陪着、每日预算和忽略后的退避判定；测试必须覆盖跨重启计数和被忽略后的频率变化。

## 阶段 5：主动陪伴的打扰预算（2026-10-16）

- 改动：`core/companion/budget.js`、`main/companion.js`、`main/ipc/companion.js`，以及 `core/monitor/{engine,privacy}.js`、`main/{agent,monitor/index,reminders}.js`、提醒规范、设置页、预加载与测试脚本。每日主动搭话上限默认 3 次，最小间隔 90 分钟；20 分钟内没有用户回应视为忽略并倍增间隔，桌宠气泡可点“稍后”立即降频。用户主动聊天或戳击后退避归零；次数和状态写入 `companion.json` 跨重启延续。
- 用户变化：可在设置页调整上限与间隔、查看今日已用次数，开启“只陪着”后仍能手动对话。勿扰和只陪着都会立即停止活动采样并压住主动开口；隐藏窗口或忙于对话时不记录未实际送达的主动话语。到期提醒在勿扰中保留待送达状态，超过 12 小时的单次提醒标为“未送达”，不会冒充完成。
- 验证：`npm test` 328/329 通过、1 项本机链接夹具跳过；`npm run build` 通过；真实 Electron M4 提醒验收 16/16（含勿扰后跨重启补送），本地模型与设置页验收 34/34。预算测试覆盖每日上限、自动与显式忽略、退避、互动恢复、跨装载状态；监测引擎在预算拒绝时不消耗规则冷却。
- 剩余风险：打扰是否被忽略按 20 分钟无聊天/戳击判断，无法确定用户是否看见气泡；桌宠“稍后”按钮和系统监测采样进程的即时停采仍需真人交互观察。提醒目前仍沿用旧结构，阶段 6 要补结果证据、失败/延期状态及可恢复承诺。
- 下一阶段前置条件：承诺簿必须把“已尝试”“已送达”“用户已完成”分开；重启后未送达提醒继续存在，Agent 工具成功声明只能来自实际执行结果。
