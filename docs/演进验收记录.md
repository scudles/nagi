## 阶段 2：安全边界（2026-10-16）

- 改动：`core/tools/files.js`、`core/tools/system.js`、`core/safety/{policy,ipc-origin}.js`、`main/ipc/*`、`main/{local-protocol,windows,index,agent}.js`、`preload/index.js`、设置页及构建配置。文件与 Live2D 模型协议检查真实路径；有副作用与敏感读取的 Agent 工具逐次确认；主进程只接受注册窗口的顶层应用页 IPC；文件目录改由系统选择器授权与撤销；预加载改为 CommonJS，渲染沙箱默认开启。
- 用户变化：文件工具没有目录授权时不可用；写入、外部控制和敏感读取会显示具体操作目标供确认；设置页可撤销目录授权。原有语音引擎与用户音色设置未更改。
- 验证：316/317 单测通过，1 项符号链接构造因本机权限跳过；源码版与便携版 M6 隔离验收各 28/28；默认沙箱下 Live2D 取景 45/45、UI 戳击/拖动 3/3、默认语音 42/42；安装版与断网复核留到阶段 10。
- 剩余风险：本机无法创建测试符号链接，需在可创建链接的 Windows 环境验证越界用例；系统目录选择器的真人交互尚待人工验收；文件系统检查到实际打开之间仍可能存在外部进程竞争，后续需结合 Windows 文件句柄策略复核。
