# 凪：经历与控制产品契约 v0.1

本契约是后续实现和验收标准，不把已有功能或交接文档标记视为通过。默认数据留在本机。人格边界以 `01_项目文档/凪_人格设定_v2.md` 为准。

| 对象 | 必须记录 / 展示 | 可测试的约束 |
| --- | --- | --- |
| 事实 | 原话或工具结果、来源、发生与记录时间、可见范围、删除状态 | 无来源的推测不得写成事实；工具失败不得记作完成 |
| 共同经历 | 双方真实参与的事件及引用的事实 ID | 跨重启能追溯；没有证据的“我们曾经”不得生成 |
| 主观记录 | 凪的日记、情绪判断和创作，明确标为主观 | 可引用事实但不得覆盖事实；召回时标明类别 |
| 主动时机 | 触发原因、距上次打扰、每日预算、勿扰与用户忽略信号 | 勿扰优先；忽略后降频；“只陪着”不主动开口；用户能停下 |
| 操作授权 | 操作名、准确目标、预期影响、确认结果 | 写文件、控制设备、浏览器动作、外部应用及命令逐次确认；拒绝后不执行；工具结果才可宣称成功 |
| 记忆纠错 | 原记录 ID、新内容、纠错时间、操作者 | 更正后旧版本不进入提示词和检索；保留可审计来源；忘记后召回为零 |
| 导出与告别 | 可读的本地包，含事实、经历、主观记录、来源、纠错与删除说明 | 离线可打开；用户可选择导出、删除或保留；告别不挽留、不制造愧疚 |

权限按信号和目标授予，可单独撤销。日历、音乐、Home Assistant 先只读验收，再开放控制。撤销后不得继续收集或调用；缺设备时仅可用明确标注的模拟事件验收代码。

固定验收场景：重启、断网、权限撤销、旧数据迁移、拒绝高影响操作、纠错后检索、删除后检索、导出再读入、取消语音、安装版与便携版。每项须记录可复现的输入、预期与实际结果。
