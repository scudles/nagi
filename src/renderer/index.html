音乐信号（只读）

单独授权后，凪可读取 Windows 当前媒体会话的曲名、歌手和播放状态。对网易云音乐等不向系统报告会话的播放器，会兜底读取其窗口标题（仅限已知播放器进程，状态未知时如实说明）。不控制播放器，不把曲目自动写进共同记忆。勿扰和“只陪着”期间暂停读取。

单独授权后，凪可获取你的大致位置（城市与坐标）。优先用 Windows 系统定位，失败时回退 IP 定位（更粗）。30 分钟内只读一次，不追踪移动轨迹，不把位置写进共同记忆。勿扰和“只陪着”期间暂停读取。

关于「活动监测」

凪 会偶尔看一眼你正在用什么程序，好在合适的时候主动关心你。

  • 只在本机判断，窗口标题原文不会保存、不会上传；
  • 密码、银行等敏感窗口默认在黑名单里，一律不采集；
  • 随时可在「设置 → 活动监测」里关闭，或临时开「勿扰」。
